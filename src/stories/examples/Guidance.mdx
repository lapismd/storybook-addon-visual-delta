# Examples

Realistic Visual Delta demos for the package Storybook. Use these to explore
baselines, overlays, Diff HTML, galleries, interactions, and modes — including
in a **static read-only** build where middleware writes are unavailable.

Each Example mounts a fixed-size **stage** (`#storybook-root`’s first child) that
matches its baseline CSS size. Baselines are 1× PNGs (built-in
`deviceScaleFactor`) with Story canvas alignment, so geometry and alignment
warnings stay off for happy-path stories.

## Reading the canvas

- A red **INTENTIONAL** banner on the canvas means the story is teaching a
  failure or empty state. Treat panel warnings / heatmaps as the demo, not a
  broken catalog.
- Match baselines are live captures of the Example stage
  (<code>pnpm examples:baselines:capture</code>). Diff HTML should pass on Match
  stories at 1×. A **geometry** warning (mismatched CSS box sizes) is not
  expected — report that as a bug in the Examples wiring. Intentional Difference
  and similar demos are meant to fail Diff HTML.

## Baseline files

Example PNGs live under
<code>tests/examples-snapshots/examples/</code> and are served at
<code>/visual-baselines/examples/…</code>. In Vite Storybook they are reached
via a symlink from the host snapshot directory
(<code>tests/visual/storybook.spec.ts-snapshots/examples</code>) because a
nested <code>staticDirs</code> mount under <code>/visual-baselines</code> is
shadowed in development.

## Static vs development

- **Static / production Storybook** — Visual Delta is read-only: gallery,
  overlay, Diff HTML, and Diff Result hydrate when sidecars exist. No Create /
  Update / Diff Browser / Run / Accept.
- **Development** — full middleware surfaces when the Vite host provides
  `/__visual-delta/*`.

## Host stubs (hidden)

Thin Shadcn / Filter / AI / Forms stubs under <code>src/stories/host-stubs/</code>
keep manager Playwright story IDs stable. They are **excluded from the default
Storybook UI** and static deploy. Manager acceptance sets
<code>VISUAL_DELTA_INCLUDE_HOST_STUBS=1</code> to load them.
