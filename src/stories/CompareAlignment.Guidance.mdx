# Compare Alignment

Regression fixtures for split inset sync, overlay session soft-hide, and
baseline chip placement. A few demos remain Svelte and mount through
`SvelteHost`; they still exercise the same preview geometry contracts.

## Requirement focus

- **`VD-UI-003`** — equal split panes, synchronized navigation, center overlay
- **`VD-UI-002`** — soft hide preserves selection; hard clear on navigation
- **`VD-CAP-002` / `VD-CAP-005`** — settled measured geometry for overlay attachment
- Baseline chip offsets stay clamped and must not alter pane geometry
