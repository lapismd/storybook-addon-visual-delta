# Panel Chrome

Browseable mounts of individual Visual Delta panel React controls (Storybook
light theme). Use these when you need a focused surface — gallery, placement
pad, accordion, history — without the full Panel Shell orchestration.

Prefer **Panel Shell** for end-to-end panel flows and Playwright panel
acceptance. Prefer **Panel Chrome** when iterating on one control.

## Requirement focus

- **`VD-UI-001`** — status badges and review pad mutate only the named concept
- **`VD-UI-002` / `VD-UI-003`** — gallery selection, placement pad soft-hide, image-only
- **`VD-UI-004`** — baseline accordion / interaction rows
- **`VD-VCS-001`** — baseline history compare UI (read-only presentation)
