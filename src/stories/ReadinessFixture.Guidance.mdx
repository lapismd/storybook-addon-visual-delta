# Readiness Fixture

Manager-oriented readiness fixture used when testing delayed missing-baseline
actions and generation-bound UI. Stories here are not product visual subjects;
they exist so manager / panel acceptance can observe readiness transitions.

## Requirement focus

- **`VD-CAP-001` … `VD-CAP-006`** — readiness, capture targets, geometry settlement
- **`VD-UI-001` / VD-GAP-005** — missing-target create actions appear after the completed render generation without requiring navigation refresh
- Story completion timing fixtures pair with Panel Shell delayed-completion stories
