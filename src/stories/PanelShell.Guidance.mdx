# Panel Shell

Live-panel-shaped self-test harness for Visual Delta manager chrome. Stories
mount the real panel shell against an in-memory mock backend so create /
update / run / review / skip-visual flows can be clicked or driven by play
functions without Playwright writes or product catalog stories.

Product visuals still run in the UI catalog host.

## Requirement focus

- **`VD-UI-001`** — coverage, outcome, review, skip, and run state stay separate concepts
- **`VD-UI-002` / `VD-UI-006`** — selection, soft hide, story-switch hard clear, remount recovery
- **`VD-UI-003`** — placement pad and split/center presentations
- **`VD-UI-004`** — modes and interaction accordion / create-for-unwired points
- **`VD-RUN-*` / `VD-MUT-*`** — run chooser scopes and guarded create/update/review actions

Full requirement tables live in the Spec mirror under
[Specification](?path=/docs/visual-delta-specification-system-specification--docs).
