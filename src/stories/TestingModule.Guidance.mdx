# Testing Module

Shared Testing Module chrome for the global runner and sidebar context menu:
run heading, play split (Create missing / Rewrite existing), action
checkboxes, progress, and visual story filters.

## Requirement focus

- **`VD-RUN-001` … `VD-RUN-006`** — frozen scopes, progress, cancellation, reconnect expectations
- **`VD-MUT-002` … `VD-MUT-006`** — create-missing / rewrite / review actions stay explicit
- Sidebar filters support “needs attention” style triage without broadening empty scopes; facet rows can include or exclude (`!` in the URL) and show matching story counts
