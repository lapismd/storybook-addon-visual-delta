# Host Stubs

Minimal stand-ins for UI catalog product stories (Button, Empty, Dialog,
Popover, Send Button, Task Due Calendar, Power Search). They keep historical
manager / overlay / sidebar **story IDs** stable after Visual Delta CSF moved
into this package.
